# 📦 Installation Guide - Frontend Dependencies

## Step 1: Navigate to Client Directory
```bash
cd "/home/itba/Desktop/ecommerce (2)/MERN/client"
```

## Step 2: Install Core Dependencies
```bash
npm install react-router-dom zustand axios
```

**Packages:**
- `react-router-dom` - Routing untuk React
- `zustand` - State management (lightweight alternative to Redux)
- `axios` - HTTP client untuk API calls

## Step 3: Install Additional Dependencies (Optional tapi Recommended)
```bash
npm install @tanstack/react-query react-hook-form zod
```

**Packages:**
- `@tanstack/react-query` - Data fetching & caching
- `react-hook-form` - Form handling yang performant
- `zod` - Schema validation

## Step 4: Verify Installation
```bash
npm list react-router-dom zustand axios
```
